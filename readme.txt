Assign custom JSON-LD schema markup to any public post type while staying compatible with popular SEO plugins.

== Description ==

Custom LD Schema adds an **LD Schema** meta box to the post editor for every enabled post type. Paste your own
Schema.org JSON-LD markup - either the complete `<script>` block or raw JSON - and the plugin stores and outputs it
with a single, standardized script tag.

When a page has a custom schema saved, the plugin suppresses the JSON-LD generated by popular SEO plugins through
their official filters, so only your custom schema is output. When no custom schema is saved, your SEO plugin keeps
working exactly as before.

**Supported SEO plugins**

* Yoast SEO
* Rank Math
* All in One SEO
* The SEO Framework
* SEOPress and other plugins via the optional strict removal mode

**Features**

* Meta box on any public post type (Posts and Pages enabled by default)
* Automatically strips the `<script>` wrapper if you paste it
* Stores only the JSON, preserving your formatting
* Validates JSON before saving
* Top-level **LD Schema** settings page
* Uses the WordPress Settings API
* Nonce verification and capability checks on every save
* Outputs exactly one `<script type="application/ld+json">` block per page
* Compatible with the Classic Editor, Gutenberg and multisite
* No front-end scripts or styles loaded

== Installation ==

1. Upload the `custom-ld-schema` folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Go to the new **LD Schema** menu to choose which post types should show the meta box.
4. Edit a post of an enabled post type, paste your JSON-LD into the **LD Schema** meta box and save.

== Frequently Asked Questions ==

= Do I need to include the `<script>` tags? =

No. You can paste raw JSON-LD or the full `<script type="application/ld+json">...</script>` block. The plugin strips the wrapper automatically.

= Will my SEO plugin still work? =

Yes. When a page has a custom schema, the plugin suppresses JSON-LD output from supported SEO plugins through their official filters. On pages without a custom schema, the SEO plugin behaves normally.

= My SEO plugin does not have an official removal filter. =

Enable **Strict removal** on the LD Schema settings page. The plugin then removes any other JSON-LD scripts from the `wp_head` and `wp_footer` output through output buffering.

= Which post types are supported? =

Every public post type, including Posts, Pages, WooCommerce Products and custom post types created by themes or plugins. Enable the meta box per post type from the LD Schema settings page.
